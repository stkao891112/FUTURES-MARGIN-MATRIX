Playwright 爬蟲在電腦端運作。若在手機端點擊「更新資料來源」，手機需要知道您電腦的 API 伺服器網址。

💡 兩種手機連線方式：
1. 同 Wi-Fi 區域網路：在電腦執行 py server.py，會顯示電腦 IP（例如 http://192.168.1.100:5000），手機用瀏覽器開啟該網址即可！
2. GitHub Pages / 外網存取：在電腦執行 ngrok http 5000，將產生的 https://xxxx.ngrok-free.app 填入下方點擊儲存！
